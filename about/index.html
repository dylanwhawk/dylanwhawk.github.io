About

Hi, I'm Dylan Hawk. I'm a research engineer based in the San Francisco Bay Area, working on AI alignment.

Most recently I designed and built a platform for creating RL tasks at scale, using an agent-plus-expert workflow: agents draft the prompt, source files, and verifiers, domain experts review and correct each stage, and the task passes through verification before it ships. I also built the systems we used to audit thousands of agent trajectories for quality, so that problems in a task showed up in its rollouts before it shipped. Before that I built enterprise agent systems and production ML, including an incident-embedding model that worked alongside an agentic workflow to cut time to resolution for on-call teams.

I'm now working on AI safety, specifically on ways to measure and improve the quality of LLM training data, especially RL environments. I think that both studying how data shapes the learning signal, and improving the pipelines that produce it, can do a lot for model alignment. Most of what I write here comes out of that work, and I'd like to hear from you if it overlaps with yours.
